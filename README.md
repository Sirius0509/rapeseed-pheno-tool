# 油菜表型拍照测量工具

一个面向油菜单株照片的 H5/PWA 测量工具，支持手机和电脑浏览器使用。

## 功能

- 上传图片或手机拍照
- 标尺校准
- 两点测量株高、主花序高、主花序长度
- 三点测量分支角
- 点击计数一级分枝
- 保存样品信息和测量结果
- 导出 Excel
- 导出带标注图片
- 支持 PWA 添加到手机主屏幕
- 独立角果/籽粒测量模块
- 调用手机、电脑或平板摄像头拍照
- 角果长度测量
- 传统图像处理生成籽粒候选点，并支持人工增删校正
- 角果和籽粒数据单独导出 Excel

## 本地运行

```bash
npm run dev
```

## 使用建议

- 每张照片优先对应一株样品。
- 植株和标尺尽量在同一平面。
- 标尺真实长度要固定并清楚记录。
- 分支计数建议只数一级分枝，点在分枝与主茎连接位置。

## 角果/籽粒模块建议

- 每张照片优先对应一个角果或一组已剥离籽粒。
- 深色背景更适合当前传统图像处理计数。
- 籽粒需要尽量分散，避免重叠和粘连。
- 拍照时镜头尽量垂直向下，光照均匀。
- 候选点结果必须人工确认，可用“补籽粒”和“删籽粒”修正。

## 云端存储

当前版本已预留“云端链接”字段，但还没有接入具体云服务。推荐后续接入 Supabase Storage + Database：

- Storage 保存角果和籽粒照片。
- Database 保存样品编号、角果编号、长度、籽粒数、照片 URL、测量日期等元数据。
- 接入后可以实现多人共享、自动分类归档和跨设备查询。

## 训练数据导出

整株模块和角果/籽粒模块都支持导出 JSON 训练数据清单。

建议模型拆分：

- 整株表型：使用关键点检测模型，例如 YOLO-pose 或 HRNet，识别标尺端点、基部、最高点、主花序端点和分枝关键点，再用几何公式计算表型。
- 角果长度：优先使用传统图像处理；背景复杂后再考虑 YOLO-seg 或 Mask R-CNN。
- 籽粒计数：建议单独使用目标检测或实例分割模型，例如 YOLO 检测模型、Cellpose/StarDist 风格模型。它不建议和整株关键点模型共用。

一个统一系统可以管理所有数据，但模型本身建议按任务拆分。
